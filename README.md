# 시니어 정리·돌봄 노트

고독사 특수청소, 유품정리, 요양원 입소 후 집 정리, 철거 견적, 병원 동행 매니저, 노인돌봄 생활지원사 정보 사이트 (Next.js, Vercel).

## 상담 버튼 링크 바꾸기

`lib/config.ts`의 `CTA_URLS`에서 탭별 제휴 상담 URL을 관리합니다. 값을 비우면 그 탭 버튼은 「상담 연결 준비 중」으로 바뀌고 링크가 나가지 않습니다.

## 원칙

- 구체 가격·결과·취업 보장 표현 금지, 공포 조장 문구 금지
- 자체 신청 폼 없음(제휴 랜딩 링크만), 광고 버튼에 「광고」 표시와 `rel="sponsored noopener"`
- 철거(무촌철거) 캠페인은 유료광고 금지 조건 — 이 사이트 같은 콘텐츠형 노출만 사용
